### 第一步：把需求逐条翻译成 API

| 需求原文               | 该问自己的话                               | 落到代码                                         |
| :--------------------- | :----------------------------------------- | :----------------------------------------------- |
| 按 10Hz 发布           | "周期性"用定时器，**不是** `while`+`sleep` | `create_timer(1.0/rate, cb)`                     |
| 发布到 `/sensor/value` | 话题名和类型**先定死**，内容最后想         | `create_publisher(Float32, '/sensor/value', 10)` |
| 幅值/频率用参数控制    | "能被外部改的数"就是参数                   | `declare_parameter` + `get_parameter`            |
| 打印验证节流           | 10Hz 全打日志会刷屏                        | `info(..., throttle_duration_sec=1.0)`           |
| 累计统计               | 边收边算，**别** `list.append` 攒着        | `count / total / max / min` 四个变量             |
| 每 2 秒打印            | 汇报频率 ≠ 数据频率 → **独立定时器**       | 再 `create_timer(2.0, on_report)`                |
| 一次启动两个节点       | 节点多了就要编排                           | `Node(...)` + `data_files` 安装                  |
| 看曲线                 | 不用自己写可视化                           | `ros2 run rqt_plot rqt_plot`                     |

		parameters=[{
            'amplitude':ParameterVlaue(LaunchConfiguration('amplitude'),value_type=float),
            'freq':ParameterVlaue(LaunchConfiguration('freq'),value_type=float),
            'rate':ParameterVlaue(LaunchConfiguration('rate'),value_type=float),      
        }],
    )
    #------------------------3.监视器节点----------------------------#
    monitor =Node(
        package='sensor_bridge',
        executable='monitor_node',
        name='monitor',
        output='screen',			# 日志打印到当前终端 screen屏幕
        parameters=[{'report_period':2.0}]
    )
    #-------------------4.返回所有launch动作会被依次执行------------------#
    return LaunchDescription([
		arg_amplitude,
        arg_freq,
        arg_rate,
        my_sensor,
        monitor,
    ])

`ROS2` 节点代码是“骨架 + 血肉“。 骨架永远是那四个接口调用，血肉才是算法

```plaintext
① 先写注释：这个节点要干什么？（一句话）
② 拆职责：要往外发？往内收？定时干活？要可配置？
③ 每个职责 → 去 dir(Node) 里找对应的 create_xxx
④ 每个 create_xxx 的参数 → 消息类型查 ros2 interface show
⑤ 最后才写业务逻辑（正弦波、统计、滤波）

```
